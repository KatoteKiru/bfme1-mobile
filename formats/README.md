# formats — форматы данных SAGE / BFME1

Владелец: **Форматы и данные**.

BIG/VFS (монтирование `.big` BFME1, порядок приоритета: игра → патч 2.22 → мобильный слой),
схема INI BFME1 (перенос из OpenSAGE, C# → C++), MAP, W3D, STR/CSF, текстуры DDS/TGA.

Файлы игры сюда не кладём. Тестовые фикстуры — только самодельные или синтетические, в `tests/`.
