# fixtures/

Реплеи для тестов (docs/REPLAY-TESTS.md §4).

- `selftest-*.rep` — только имена для `fake_engine.py` (он их не читает); файлов может не быть.
- **Реплеи можно хранить в приватном репозитории** (решение Оркестратора 02.10.2026): `.rep` — это только
  журнал команд игроков, без ассетов игры. Правила:
  - **один файл ≤ 1 МБ**; больше — не коммитим (укоротить сценарий или держать на боксе в `$BFME_REPLAYS`);
  - **без git LFS** и без больших наборов: в git — только реплеи, на которые ссылается `manifest.toml`;
  - имя = имя кейса: `fixtures/<case>.rep`; в описании коммита — откуда реплей (кто записал, сборка, сид).
- Карты и данные игры, нужные для проигрывания, в git **не попадают никогда**: они лежат на боксе
  (`$BFME_GAMEDATA`, см. `docs/game-files-access.md`).
- Реплеи Zero Hour (из `GeneralsReplays`) — только когда ZH будет куплен; пока не планируем.
