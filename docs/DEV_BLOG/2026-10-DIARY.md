## 2026-10-08: logic-thread FP gate (ADR-0003 §2.3)

`fp::bindLogicThread()` is the first call in `GameMain()`, before the engine
init. `GameLogic::init` and `setFPMode()` compare `std::thread::id`. Debug and
CI abort on a mismatch or on a check that happened before the bind. Release
logs once; if nothing was bound yet, that log is followed by binding the
caller. A second bind from another thread aborts only in debug. The Android
debug thread-name check warns when the name is not `SDLThread` and does not
abort. `gettid()` is only in the log line.

`setFPMode()` is a wrapper over `fp::reset()`. The stub's `reset()` is the
previous non-VC6 body (`fesetenv`, `feclearexcept`, `fesetround(FE_TONEAREST)`,
and on x86 the x87 control word and MXCSR nearest). `read()` and
`isExpected()` stay trivial until Platform replaces the file. VC6 still
compiles the old `setFPMode()` in place. `g_mode` is `std::atomic` and is
read and written with relaxed ordering.

## 2026-10-08: E1-21b BFME VFS hook

`createArchiveFileSystem()` now returns `BfmeBIGFileSystem` only when
`BFME_GAMEDATA` is set and non-empty. Otherwise it still returns
`StdBIGFileSystem`. `formats/vfs/src` is compiled into `z_gameenginedevice`.
The Android device library was not built here.

## 2026-10-02: `-gxCrcLog` for QA replay tests

QA needs the logic CRC of every frame in its own file, without turning on the
network trace. `-gxCrcLog <path>` writes `bfme-crclog/1` (frame CRC plus the
running CRC after Objects, Partition, PlayerList, and AI). It is off unless
the option is passed. The checksum is the existing `getCRC(CRC_RECALC)` path,
Xfer in CRC mode, and the logic seed is only read.

The exit footer remembers the last frame written. `atexit` runs after
`GameLogic` is gone, so it must not call `getFrame()`. With `-jobs N` the
parent only spawns workers; those workers now receive the option and each
opens `<stem>.<replay>.<pid><ext>`. `-jobs 1` is what QA should use. The
header records `# logic_hz=` because the replay file does not store the tick
rate (30 unless the 60 Hz build is on).

Not run here: a headless replay. The first one should show the same final CRC
and gamestats with and without the flag, and should check the suspected +1
offset (CRCs in the replay sit on frames 1, 101, 201, …).
