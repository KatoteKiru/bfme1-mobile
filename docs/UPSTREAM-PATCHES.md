## Точки подключения своего сервера и своего OTA (E1-04)

Чужие части вырезаны (автообновление форка и его манифест, онлайн-сервис форка, сетевой
`GXRemoteConfig`). Вместо них оставлены пустые точки подключения. URL по умолчанию нет: пустое
значение = функция выключена.

| Файл | Что это | Как включить |
|---|---|---|
| `android/app/build.gradle` | `buildConfigField` `BFME_OTA_URL` и `BFME_ONLINE_URL` (пометка `// BFME:`), `buildFeatures.buildConfig true` | `-PbfmeOtaUrl=https://…` / `-PbfmeOnlineUrl=https://…`; без свойства — пустая строка |
| `android/app/src/main/java/com/generalsx/zerohour/UpdateProvider.java`, `NoopUpdateProvider.java` | интерфейс обновлений; `UpdateManager.check()` делегирует `UpdateProvider.forBuild()` | написать реализацию и вернуть её из `forBuild()`, когда `BFME_OTA_URL` не пуст. Сейчас всегда no-op |
| `android/app/src/main/java/com/generalsx/zerohour/OnlineProvider.java`, `NoopOnlineProvider.java` | интерфейс онлайна; `GeneralsZHActivity.onCreate` вызывает `refreshSessionAsync` | реализация для своего сервера, выбирается в `forBuild()` по `BFME_ONLINE_URL` |

Требование к OTA: провайдер обязан проверять подпись манифеста (ECDSA P-256 по точным байтам)
нашим собственным публичным ключом (ключ форка `PUBLIC_KEY_B64` удалён вместе с кодом загрузки и проверки в `UpdateManager`) и монотонность `serial` до того, как что-либо
записать или загрузить; файлы движка — по SHA-256 из подписанного манифеста. Приватный ключ в
репозиторий не попадает.
