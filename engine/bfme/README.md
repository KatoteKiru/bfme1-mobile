# engine/bfme — слой геймплея BFME1

Владелец: **Геймплей** (BFME: Геймплей). Архитектура и ревью: **Лид движка**.

Код слоя BFME1 поверх движка Generals/Zero Hour: орды и построения, слоты застройки и здания,
ресурсы, найм, апгрейды, герои и уровни, силы (power points), стены и ворота, AI скирмиша.

Правки движка вне этого каталога идут через ревью Лида движка (`engine/`, ADR в `docs/adr/`).
